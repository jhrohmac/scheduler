# AI 예측 확인 플로우 (On-demand)

## 목표
- 사용자가 특정 종목을 선택해 "AI 예측"을 요청하면,
- 이미 저장된 배치 분석 데이터(일봉/30분/이벤트/레짐)를 기반으로
- 2차 검토 결과(상승/중립/하락 확률, 근거, 리스크)를 반환.

## 입력
- stock_code
- 요청 시점(현재)
- 옵션(기간: 5D/20D/60D, 보수/중립/공격)

## 데이터 소스
- TB_S_STOCK_ANALYSIS
- TB_S_STOCK_30MINANALYSIS
- TB_S_SIGNAL_EVENT
- (향후) TB_S_RECO_EVAL / VW_S_RECO_PICK_STATS

## 처리 로직(초안)
1) 최신 분석 스냅샷 로드
2) 이벤트/레짐/지표 기반 피처 구성
3) 규칙+통계(초기) 또는 모델(확장)로 확률 산출
4) 결과 생성
   - 상승/중립/하락 확률
   - 근거 TOP3
   - 반례/리스크 TOP2
   - 권장 액션(관망/분할진입/보수적 접근)

## 출력(UI)
- "AI 재검토 카드"
  - 방향 확률(%)
  - 신뢰도(낮음/중간/높음)
  - 근거/리스크
  - 만료시각(as-of)

## 운영 원칙
- 자동매매 신호로 바로 사용 금지(초기)
- 설명가능성(근거 문장) 필수
- 확률은 의사결정 보조로만 사용
