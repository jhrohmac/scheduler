📊 BullishMomentumDetector 데모

이동평균선 정배열 + 장대양봉/연속양봉 패턴 감지 모듈

📖 패턴 설명

1️⃣ 이동평균선 완전 정배열

close > MA5 > MA20 > MA60 > MA120 > MA240

모든 기간의 이동평균이 상승 정렬 → 매우 강한 상승 추세

2️⃣ 장대양봉 (Long Bull Candle)

조건: 현재 캔들의 실체 ≥ 최근 20일 평균 실체 × 2.0배
실체: |close - open|
의미: 평소보다 2배 이상 큰 양봉 → 강력한 매수 추진력

3️⃣ 연속양봉 (Consecutive Bullish Days)

조건: 3일 이상 연속 close > open
의미: 지속적인 상승 추세 확인 → 매수력 지속

📈 종합 의미

상승 추세 초입(Golden Cross) + 강한 매수 추진력
이 패턴이 나타나면 강한 상승 신호이며, 매수 시점 파악에 활용할 수 있습니다.

🔧 구현 상세

최소 요구사항

  • 캔들 수: 최소 240개 (MA240 계산을 위해)
  • 데이터 구조: [time, open, high, low, close, volume]
  • 시간 단위: 일별 데이터 권장

파라미터

파라미터 기본값 설명
consecutiveBullDays 3 연속양봉 기준 일수
longCandleRatio 2.0 장대양봉 배율 (평균 실체의 몇 배인지)

신호 유형

  • LONG_BULL_BODY 장대양봉 신호 (실체가 2배 이상)
  • CONSECUTIVE_BULL 연속양봉 신호 (3일 이상)

🌐 API 사용법

REST 엔드포인트

POST /scheduler/finance/detectBullishMomentum.do

요청 파라미터

파라미터 필수 설명
stockCode ✓ 종목 코드 (예: 005930)
stockName 종목명 (선택)

consecutiveBullDays 기본값 3

💻 클라이언트 라이브러리 사용법

1. 라이브러리 로드

<script src="/scheduler/appone/jsp/finance/kis/kisFinance/js/bullishMomentumDetector.js"></script>

2. 인스턴스 생성

const detector = new BullishMomentumDetector({
    consecutiveBullDays: 3,
    longCandleRatio: 2.0,
    apiEndpoint: '/scheduler/finance/detectBullishMomentum.do'
});

3. 신호 감지 (API)

detector.detectFromChart(chartData, '005930', '삼성전자')
    .then(signals => {
        console.log('감지된 신호:', signals);
        detector.renderSignalsTable(signals, 'tableContainerId');
    });

4. 신호 테이블 렌더링

<div id="bullishSignals"></div>

<script>
    detector.renderSignalsTable(signals, 'bullishSignals');
</script>

⚠️ 기술적 어드바이스

이 패턴의 장점

  • ✓ 강한 상승 추세를 명확하게 감지
  • ✓ 여러 시간대의 이동평균을 동시에 확인
  • ✓ 장대양봉과 연속양봉으로 추진력 확인

한계 및 주의사항

  • ⚠️ 거짓 신호: 단독으로는 위험하며, 추가 필터 필수
  • ⚠️ 시간차: 차트 업데이트 지연으로 신호 지연 가능
  • ⚠️ 약세장: 약세장에서는 신뢰도가 낮음

권장 추가 필터

  • 💡 RSI: RSI < 70 (과매수 상태 제외)
  • 💡 MACD: MACD 골든크로스 확인
  • 💡 거래량: 거래량 증가 추세
  • 💡 지지/저항: 주요 가격 수준 고려

면책조항

이 분석 도구는 기술적 분석을 위한 참고만 되며, 절대 투자 조언이 아닙니다.
실제 투자 결정 시에는 전문가의 조언을 반드시 구하시기 바랍니다.
