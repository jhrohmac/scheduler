# 1-1 관심종목(Watchlist) UI 세부 플로우

## 사용자 플로우(요약)
1) 관심종목 그룹 선택
2) 관심종목 리스트 로드
3) 현재시점 상태 확인
   - 분석 최신시각(일봉/30분)
   - 신호/점수 요약(가능하면)
   - 시장 레짐 요약(가능하면)
4) 종목 클릭 → 차트/상세로 이동

## 화면 요소(권장 표준)
- 최신 분석 시각 배지: DAY.modify_date / 30MIN.modify_date
- 시그널 배지: reco_signal 또는 MACD/정배열 핵심 1~2개
- 레짐 배지: KR/US 레짐 상/중/하(요약)

## 연관 API/채널
- 관심종목 그룹/목록 조회
- (옵션) 웹소켓/캐시 현재가

## 연관 DB
- TB_S_INTEREST_STOCK
- TB_S_STOCK_ANALYSIS
- TB_S_STOCK_30MINANALYSIS

## 다음 개선 후보(UX)
- “분석 오래됨” 강조(예: 3일 이상)
- 클릭 시 오른쪽 패널에 요약 카드(신호/이벤트 최근 3개)
