# 최종 단계: 실계좌 연동 자동 매수/매도 (Auto Trading)

## 목표
- 프로젝트 소스/백테스트/모니터링이 안정화된 이후, 실제 증권 계좌(KIS 등)와 연동해 자동 주문을 실행.

## 전제(필수)
- 추천/튜닝 지표가 안정적으로 개선되고, 실패 케이스(급락/갭/레짐 붕괴)에 대한 방어 로직이 준비되어야 함
- 주문 전 "시뮬레이션(페이퍼)" 단계로 충분히 검증

## 단계 제안
1) 페이퍼 트레이딩(모의) 모드
2) 실계좌 연결(소액/제한된 종목/제한된 횟수)
3) 주문 정책 강화(리스크/쿨다운/손절/서킷)

## 필요 구성요소(예)
- 주문 API 클라이언트(KIS 주문/정정/취소)
- 주문/체결/포지션 상태 저장 테이블(TB_S_ORDER, TB_S_TRADE, TB_S_POSITION 등)
  - DB 초안: `51_AUTO_TRADING_DB_DRAFT.md`
- 안전장치
  - 1일 최대 주문수/금액 제한
  - 레짐 하(비우호)에서는 자동매매 OFF 또는 강한 제한
  - 긴급 정지 스위치(수동)
  - 로그/감사(Audit)
