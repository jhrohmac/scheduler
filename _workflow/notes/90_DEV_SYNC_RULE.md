# 개발 동기화 규칙 (Workflow ↔ Source)

앞으로 소스 로직 작업 시 아래 규칙을 기본으로 적용:

1) Workflow 선반영
- 신규 기능/모듈/테이블/신호는 먼저 워크플로우 노드에 추가 또는 상태 변경

2) Source 구현 동시 반영
- 워크플로우에 적힌 항목을 소스로 구현
- 구현 후 워크플로우 상태를 ✅/🟡/⬜로 즉시 업데이트

3) 중복 방지
- 같은 목적 모듈이 이미 있으면 재사용 우선
- 신규 모듈 생성 시 기존 모듈/테이블과 충돌 여부 확인

4) 명명 규칙 준수
- DB: TB_S_* / VW_S_*
- 신호 타입: TIMEFRAME_의미_조건 형태 유지

5) 싱크 체크(작업 종료 기준)
- Workflow 노드 설명과 실제 코드가 일치하는지 확인
- API/배치/DB/UI 중 영향 범위를 노드 연결로 표시

6) 변경 단위 원칙
- 기능 단위(작게)로 구현/검증
- 빌드/기동 확인 후 다음 단계 진행
